## Diferencias con Sprint 1 y prototipo

La auditoría de la entrega 01 confirmó la omisión del original 2024: una regla Git lo excluyó de la selección. La revisión 02 exige una lista de insumos y recursos web independiente de `.gitignore`, tanto para firma como para empaquetado. El cotejo CRC/SHA de elementos enumerados se complementa con comprobación de completitud y ejecución aislada desde ambos originales.

El exportador web valida dimensiones, unidades, nulos y denominadores, y no implementa una segunda normativa. La aplicación representa resultados procesados: las proporciones y escalas visuales no son un nuevo cálculo del índice. La matriz horaria usa <75% de horas evaluables solo como señal visual de cobertura, no como nueva regla de compleción de NowCast. Las clasificaciones de menor/mayor media mensual consideran únicamente la población elegida y meses suficientes; no convierten una concentración media en un nivel global de riesgo.

Se mantiene la composición común de cuatro contaminantes y el disponible parcial por separado. Los episodios que cruzan de año conservan intervalo y duración originales aunque coincidan con filtros de ambos años. Meteorología tiene controles explícitos de un solo mes/año y conserva los puntos exactos; el valor inicial PM10/ET de diciembre 2024 tiene datos. NO2 dispone únicamente de un apartado exploratorio 2024.

Las figuras se generan con Matplotlib 3.10.8 (nueva dependencia necesaria para exportación científica SVG/PNG). No cambian las versiones numéricas ni dependencias web anteriores; se amplía el lock Python con sus dependencias transitivas. Se conserva la familia visual del sitio existente y se reutilizan navegación y tema. El build se limita a la raíz de la aplicación para que no descubra locks ajenos al extraer sin Git.

Se conserva `pipeline/nom172.py`, sus pruebas docentes y todos los archivos previos. La referencia docente redondea antes del ajuste y usa `round()`; Sprint 2 sigue el orden de operaciones de la NOM. Por ejemplo, ventana constante PM10=62.5: Sprint 2 devuelve 45 y la referencia de Sprint 1 devuelve 44. No se atribuye a la docente aprobación de esta revisión.

El PDF entregado del Sprint 1 emplea límites aceptables PM10=70 y PM2.5=41; el código actual del repositorio emplea 60 y 33. El análisis retrospectivo utiliza explícitamente la referencia 2024: 60 y 33. La guía local contiene una recomendación genérica de límites 2026 y el signo “<” en algunos intervalos; se conserva como evidencia previa y se aplica el encargo de esta fase. La inspección visual del PDF oficial (pp. 10–11) confirma los límites inclusivos “≤” de Buena. La extracción de texto había omitido el trazo del símbolo: no hay un hueco normativo en esos límites.

El prototipo redondeaba JSON a seis decimales, promediaba códigos GLOBAL y llamaba EXACT_CO al máximo de una media móvil ya redondeada. Se corrigen esas tres cuestiones; las discrepancias numéricas y de categorías se entregan en comparacion_prototipo.csv y el informe de verificación. Los CSV de source de esta revisión contienen todas las columnas originales de MIR, número de fila y archivo; sus hashes difieren del prototipo por esa trazabilidad, sin alterar las mediciones.

El control independiente detectó además una diferencia real de aritmética: en 2024-03-23 22:00, el promedio de ocho horas de CO es exactamente 0.485 ppm; el cálculo flotante del prototipo generaba un valor apenas inferior y lo redondeaba a 0.48. Se usan sumas y promedios con Decimal en CO, PM diario y ponderación NowCast, además del redondeo decimal final. El resultado correcto de esa ventana es 0.49 ppm. Se añade una prueba específica y se registran todas las discrepancias; no se exige coincidencia numérica con un redondeo erróneo anterior.
